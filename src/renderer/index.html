    See your assigned work while you work.

    Plane Pin is a small task rail that can stay above your other apps. Setup takes about two minutes.

    • Only tasks assigned to your Plane account
    • All projects together, or one project
    • All workflow states, or exactly the states you choose

    Start from any Plane page

    Open Plane in your browser and copy its address. A task or My Work page both work.

    Example plane.example.com/my-workspace/browse/TEAM-12

    We use the domain and highlighted workspace name.

    Create a personal access token

    This lets Plane Pin read your assigned tasks. It cannot edit them.

    1. In Plane, open your profile or avatar menu.
    2. Choose Settings, then Personal access tokens.
    3. Select Add token, name it “Plane Pin,” and copy it.

    Stored with Windows encryption and never exposed in the task list.
