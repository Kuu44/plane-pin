    See your assigned work while you work.

    Plane Pin is a small task rail that can stay above your other apps. Setup takes about two minutes.

    • Choose one, several, or every workspace member
    • Mix tasks from any accessible projects
    • Pick the exact workflow states you want to see

    Paste your workspace home address

    The site address and workspace name Plane Pin needs are both in this one URL.

    1. Open Plane in your browser and select the workspace you want to connect.
    2. Go to that workspace’s Home page.
    3. Copy the address from your browser and paste it below.
    Example https://plane.example.com/my-workspace/

    The highlighted part is the workspace slug Plane Pin needs.

    Create a personal access token

    This lets Plane Pin read your assigned tasks. It cannot edit them.

    1. In Plane, open your profile or avatar menu.
    2. Choose Settings, then Personal access tokens.
    3. Select Add token, name it “Plane Pin,” and copy it.

    Stored with your operating system’s secure credential storage and never exposed in the task list.

    Whose tasks should appear?

    Choose any combination of members from this workspace.

    Which projects should appear?

    Select any combination of projects. Everything is selected by default.

    Which workflow states should appear?

    These exact state names come directly from the selected projects.

    What should a checkmark do?

    Choose the next state for each workflow step. The final state can have no action.

    Make the rail yours

    These defaults and every connection value can be changed later in Settings.

    Quick controls

    Hover toolbar controls to see shortcuts. Tasks refresh every five minutes by default.
